# Sprint_7 - Тестирование API Яндекс.Самокат

## Описание проекта
Проект содержит автоматизированные тесты для API сервиса Яндекс.Самокат. Реализовано тестирование основных ручек API с проверкой позитивных и негативных сценариев.

### Установка зависимостей
```bash
pip install -r requirements.txt
```
## Запуск тестов

### Все тесты
```bash
python -m pytest tests/ -v
```
### С генерацией Allure отчета
```bash
python -m pytest tests/ -v --alluredir=target/allure-results
```
### Просмотр Allure отчета
```bash
allure serve target/allure-results
```

# Баги
## Баг: При авторизации без пароля возвращается 504 вместо 400

Ожидаемый результат: Сервер должен вернуть HTTP 400 Bad Request и тело: "message": "Недостаточно данных для входа"

Фактический результат: Сервер возвращает HTTP 504 Gateway Timeout. Ответ об ошибке отсутствует или сервис недоступен
## Баг: При удалении курьера без ID возвращается 404 вместо 400

Ожидаемый результат: Сервер возвращает: HTTP/1.1 400 Bad Request "message": "Недостаточно данных для удаления курьера"

Фактический результат: Сервер возвращает: HTTP/1.1 404 Not Found "message": "Not Found."
## Баг: API не принимает заказ при корректных данных — возвращает 404 вместо 200

Ожидаемый результат: HTTP/1.1 200 OK "ok": true

Фактический результат: HTTP/1.1 404 Not Found "message": "Заказа с таким id не существует"
## Баг: API возвращает 404 вместо 400 при попытке принять заказ без передачи номера заказа

Ожидаемый результат: HTTP/1.1 400 Bad Request "message": "Недостаточно данных для поиска"

API должно валидировать отсутствие обязательного параметра и вернуть 400.

Фактический результат: HTTP/1.1 404 Not Found "message": "Not Found."
## Баг: Невозможно протестировать повторное принятие заказа, т.к. API не принимает заказ даже при валидных данных
